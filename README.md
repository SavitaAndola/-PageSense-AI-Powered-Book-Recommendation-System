# 📚 PageSense – AI Powered Book Recommendation System

PageSense is a web-based application that helps users discover books based on their mood and interests. Instead of randomly searching, users can get meaningful suggestions along with book covers, author names, and short descriptions. The goal of this project is to make book discovery simple, fast, and more personal.

---

## ✨ Features

* 🔍 **Mood-Based Recommendations**
  Select your mood and get books that match how you feel

* 📖 **Book Details Display**
  Shows book cover, author name, and description

* 🎯 **User-Friendly Interface**
  Clean layout so anyone can use it without confusion

* ⚡ **Fast & Lightweight**
  Runs directly in the browser without heavy setup

* 💬 **(Optional Feature)** Chatbot support to guide users

---

## 🧠 How It Works

The system takes user input (like mood or preference) and matches it with a dataset of books. Based on this, it suggests books that best fit the user's interest.

The idea is simple:

> Input → Process → Recommendation Output
